# Δεδομένα εισόδου (δεν περιλαμβάνονται στο repository)

Τα αρχεία αυτά είναι μεγάλα και/ή έχουν δικούς τους όρους χρήσης, γι' αυτό δεν γίνονται commit
(βλ. `.gitignore`). Κατέβασέ τα από τις πηγές που αναφέρονται στο `config.yaml` (ενότητα
`metadata.sources`) και τοποθέτησέ τα εδώ με τα ονόματα του `config.yaml`:

| Κλειδί | Αρχείο | Περιγραφή |
|---|---|---|
| dem | `DEM_2100.tif` | Ψηφιακό μοντέλο εδάφους, ΣΑ EPSG:2100 (ΕΓΣΑ87) |
| wind | `GRC_wind_speed_100m.tif` | Μέση ταχύτητα ανέμου στα 100 m |
| regional_units | `RegionalUnits2021.shp` | Περιφερειακές Ενότητες (πεδίο `NAME_GR`) |
| settlements | `settlements2021.shp` | Οικισμοί |
| natura | `N2000_spatial_GR_2020_08_10.shp` | Περιοχές Natura 2000 |

Για να ελέγξεις ότι έχεις τα ίδια ακριβώς δεδομένα με την αρχική εκτέλεση, σύγκρινε τα SHA-256
του `data/processed/provenance.json` (ενότητα `inputs`) με `sha256sum data/raw/*`.
